 Dental Clinic - Website

Official website for ** Dental Clinic**,, Tamil Nadu. The clinic provides advanced dental treatments including painless root canal therapy, orthodontics (braces and invisible aligners), dental implants, cosmetic smile designing, and pediatric dentistry.

---

## 📋 Features

- **Multi-Page Layout**: Dedicated pages for clinic background, services, treatments, contact details, and appointment booking.
- **Service & Treatment Showcases**:
  - Root Canal Treatment (`root-canal.php`)
  - Orthodontics & Clear Aligners (`orthodontics.php`)
  - Dental Implants (`implants.php`)
  - Cosmetic Dentistry & Smile Design (`cosmetic.php`)
  - Pediatric Dental Care (`pediatric.php`)
  - Overview of all services (`services.php`)
- **Online Appointment Booking**: Simple booking interface for prospective patients (`book-appointment.php`).
- **Interactive Contact & Location**: Direct contact form, clinic hours, contact numbers, and embedded Google Maps integration (`contact.php`).
- **Responsive & Modern Styling**: Custom responsive CSS (`css/style.css`) with modern layouts, cards, and mobile-friendly navigation.
- **Quick Patient Touchpoints**: One-click WhatsApp chat integration and direct call buttons across all pages.

---

## 🛠️ Tech Stack

- **Backend / Templating**: PHP
- **Frontend / Markup**: HTML5, CSS3 (Vanilla CSS)
- **Icons**: Font Awesome (v5/v6)
- **Server Environment**: Apache / PHP (compatible with XAMPP, WampServer, LAMP, or any standard PHP hosting)

## 🚀 Getting Started (Local Development)

### Prerequisites

- [XAMPP](https://www.apachefriends.org/) (or any PHP web server with PHP 7.4 or higher)

### Setup Instructions

1. **Clone or Place the Directory**:
   Place the project folder into your web server's document root (e.g., `htdocs` for XAMPP):
   ```text
   C:\xampp\htdocs\nithya_dental_clinic
   ```

2. **Start the Web Server**:
   - Open the **XAMPP Control Panel**.
   - Click **Start** on the **Apache** service.

3. **Access the Website**:
   Open your browser and navigate to:
   ```text
   http://localhost/nithya_dental_clinic/
   ```
